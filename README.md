# Sistema-academia
Sistema de gerenciamento de acdemia
📊 Status do Projeto
🚧 Em Desenvolvimento 🚧
💻 Tecnologias Utilizadas

Linguagem: Java (JDK 8+)
Interface Gráfica: Swing (javax.swing)
Banco de Dados: MySQL
Conectividade: JDBC (MySQL Connector/J)
IDE: NetBeans / Eclipse
Versionamento: Git / GitHub

👥 Time de Desenvolvedores

Denis Saldanha - Desenvolvedor Principal

🎯 Objetivo do Software
Sistema desktop para gerenciamento completo de academias, permitindo controle de alunos, planos de mensalidade, matrículas e geração de relatórios. O sistema visa automatizar processos administrativos, facilitando o trabalho da recepção e gerência.
⚙️ Funcionalidades do Sistema
Módulo de Autenticação

Login de usuários com diferentes níveis de acesso
Controle de permissões (Administrador, Recepcionista)

Gestão de Alunos

Cadastro de alunos com dados completos (nome, CPF, telefone, e-mail)
Validação de CPF único
Listagem de todos os alunos cadastrados
Consulta por CPF

Gestão de Planos

Cadastro de planos de mensalidade
Definição de valores e duração
Descrição detalhada de cada plano
Visualização de todos os planos disponíveis

Gestão de Matrículas

Processo de matrícula de alunos
Vinculação de aluno a plano
Cálculo automático de data de vencimento
Controle de status (Ativa, Pendente, Cancelada)
Consulta de matrículas com filtros

Relatórios

Relatório de alunos cadastrados
Relatório de planos disponíveis
Relatório de matrículas ativas
Resumo geral com estatísticas
Cálculo de receitas

Recursos Adicionais

Interface gráfica intuitiva e profissional
Navegação fluida entre telas
Validações de dados
Feedback visual ao usuário
Gerenciamento de fornecedores

🗃️ Estrutura do Banco de Dados

Tabela usuarios: Controle de acesso ao sistema
Tabela alunos: Cadastro de alunos
Tabela planos: Planos de mensalidade
Tabela matriculas: Registro de matrículas
📋 Requisitos do Sistema

Java JDK 8 ou superior
MySQL Server 5.7 ou superior
MySQL Connector/J (Driver JDBC)
512MB RAM mínimo
50MB espaço em disco
